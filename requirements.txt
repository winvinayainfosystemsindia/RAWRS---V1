# RAWRS — direct runtime dependencies.
#
# These are pinned to exact versions so a fresh clone reproduces the
# environment that produced the current test baseline. The COMPLETE graph,
# including every transitive package, is in requirements.lock.
#
#   Reproducible install (preferred):  pip install -r requirements.lock
#   Intent-level install:              pip install -r requirements.txt
#
# rapidocr is declared here even though nothing in RAWRS imports it directly.
# It arrives transitively via docling (which accepts rapidocr>=3.3,<4.0.0) and
# was previously undeclared and unpinned, so it drifted to 3.9.0. On 3.9.0 the
# default torch backend rejects model id PP-OCRv6.det.small, which is the sole
# cause of the failing real_docling integration test. Pinning it here makes
# that failure deterministic and visible rather than a moving target.
# See docs/P0-1_DEPENDENCY_PINNING_2026-07-19.md for the fix options.
#
# onnxruntime is declared here because docling's rapidocr integration needs it:
# rapidocr 3.9.0's torch backend cannot serve the PP-OCRv6 model family that
# docling 2.87.0 requests, but its onnxruntime backend can. P0-1 diagnosed this
# and prescribed installing onnxruntime as its own task; that task is done now,
# and the real_docling integration tests pass with it installed (2026-09-15).

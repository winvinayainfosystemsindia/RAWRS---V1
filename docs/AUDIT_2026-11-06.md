## Bugs found by running it on a real site (all fixed, with tests)
| Bug | Fix |
|---|---|
| CivicPlus serves PDFs without a `.pdf` suffix (`/DocumentCenter/View/123/Name`), so the first run found 0 | Links under document folders are candidates; one counts only if its bytes start with `%PDF` |
| Link rules (7.18.x "alternate description") were counted as images without descriptions | `check_of` excludes every 7.18.x clause |
| The same file was reached via www and non-www addresses, or via two addresses | Dedupe by host, path and query, then by content hash |
| Relative `Sitemap: /sitemap.xml` in robots.txt | Joined to the site URL |
| LibreOffice's HTML import tags `<h1>` wrongly (7.4.2 fails even for plain h1/h2) | The report PDF is built from a DOCX (the Task 3 route) |

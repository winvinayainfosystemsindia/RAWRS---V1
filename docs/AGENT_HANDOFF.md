## 1. What RAWRS is

**RAWRS** (Remediation & Accessibility Work Reduction System) is a PDF-accessibility
remediation platform.

- **Backend:** FastAPI (Python). Runs on **port 8001** (frontend expects
  `NEXT_PUBLIC_API_BASE_URL=http://127.0.0.1:8001` in `frontend/.env.local`).
- **Frontend:** Next.js (port 3000).
- **Primary input:** a **Mathpix package** (MMD import), not raw PDF OCR, for the main path.

**Pipeline:** parse PDF → extract text (native + OCR **or** Mathpix MMD import) →
structure detection → image extraction → heading detection → **inspection** (the
single correction stage) → **link** (relationships + paragraph assembly) →
Markdown + DOCX projection → validation.

**The Document Model is the source of truth.** Markdown and DOCX are projections
of it, and neither owns semantics. (DOCX is still *generated by parsing* the
Markdown today — that is known debt, tracked as P4, not the intended design.)
Correctness of a projection is measured against the model, not against a previous
rendering: see `docs/ADR_PROJECTION_CORRECTNESS_2026-08-03.md` (ADR-020) and run
`python -m src.benchmark --projection samples/benchmark/pdfs`.

Canonical model: `Document` (in `src/models/`). Contracts re-exported via
`src/models/contracts.py`.

## 2. Ground rules (these override defaults — obey them)

1. **NEVER push.** Commit locally only. The user pushes.
2. **One roadmap unit = one local commit**, independently reversible. One commit =
   one architectural idea.
3. **Mandatory preflight before implementing anything:** prove the item is *not
   already built*. Trust order: **Benchmark > Repository > Runtime > Documentation >
   Memory.** If it already exists → STOP, write an investigation note, do not commit.
4. **Auto-commit only if ALL validation gates pass.** Do not wait for confirmation
   *iff* every gate is green. If any gate fails → STOP, report, do not commit.
5. **Stop conditions** (→ stop, investigate, do not continue): roadmap assumption
   false, duplicate implementation found, benchmark regression, failing tests, scope
   expansion beyond the one unit.
6. **KPI rule:** every commit must **improve or preserve** a measurable Phase-2 KPI
   (justify if only preserving).
7. **Additive units:** nothing may consume new evidence yet; behaviour/output
   unchanged; **production must never import benchmark-only code**.
8. md-file deliverables must be **brief**: tables + one-line evidence, not long prose.

## 6. Cross-source verification & readiness (prior phase, DONE)

- Engine: `Finding → CorrectionRecord` (accept/reject/edit/ignore/undo, reversible
  apply/revert) **+** `ValidationIssue` (read-only mirror).
- `CorrectionStatus` — 8 states: PROPOSED, AUTO_APPLIED, ACCEPTED, REJECTED, EDITED,
  IGNORED, PENDING_REVIEW, REVERTED.
- **Readiness is canonical on `AccessibilityReport.export_ready`**
  (`= len(blocking_failures) == 0`). Snapshot `/readiness` + `/export-readiness`
  endpoints were **retired**; `compute_readiness` demoted to diagnostics.
- **`CorrectionTerminalRule`** (`rule_id REVIEW_001`, OBSERVATION,
  `required_for_export=True`, MANUAL): non-terminal `{PROPOSED, PENDING_REVIEW,
  REVERTED}` → MANUAL_REVIEW_REQUIRED (blocking); terminal `{ACCEPTED, EDITED,
  REJECTED, IGNORED, AUTO_APPLIED}` → PASS; no corrections → `[]`.
- **Accessibility engine** (`src/accessibility/`): rules registry,
  `EvidenceBundle`/`EvidenceSignal`, `BarrierClass` (BARRIER=10 / DEGRADATION=5 /
  OBSERVATION=2), `RuleOutcome` (PASS/FAIL/MANUAL_REVIEW_REQUIRED/NOT_APPLICABLE).
  **Rules self-register at import** — you MUST `import src.accessibility.rules` or the
  registry is empty (a vacuous 100% / `export_ready=True`; this bit us once). 15 rules
  registered.

## 7. Gotchas that already burned us

- **Empty rules registry** → false "engine too permissive". Always
  `import src.accessibility.rules` before scoring.
- **Edit-script substring collisions:** when patching with asserted
  `text.count(old)==n`, use a unique multi-line anchor (a 2-space-indented pattern
  matched an 8-space line as a substring).
- **F0 report is in-memory** unless you pass `--out`; write to a file if the user asks
  "where is the report".
- Jest: `@testing-library/user-event` is not installed — use `fireEvent`.
- Rule-count fixture: `test_accessibility_engine.py` asserts the rule count; bumping
  rules means bumping the fixture.
